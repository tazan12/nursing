Lead II는 우측 상지에서 좌측 하지 방향으로 심장의 하벽 방향 전기활동을 관찰합니다.

12-lead 흉부 위치 기억법

V1·V2: 제4늑간 흉골연 → V4: 제5늑간 쇄골중앙선 → V3: V2와 V4 사이 → V5·V6: V4와 같은 수평선.

표준 12-le드는 10개 전극으로 12개 lead를 만듭니다. 실제 부착은 기관 정책과 장비 설명서를 따르세요.

수동 제세동기 의사결정 훈련

리듬 이름보다 먼저 환자 반응·호흡·맥박을 확인하고, 심정지의 충격 가능 리듬인지 판단합니다.

시나리오를 선택하세요.

훈련 순서

① 반응·호흡·맥박 확인, CPR 지속 중 리듬 판독
② VF/pVT만 비동기 제세동, PEA/무수축은 충격하지 않음
③ 제조사 권장 에너지 설정 후 충전
④ 산소원·침상·사람 접촉을 눈으로 확인하고 CLEAR
⑤ 단일 충격 직후 맥박 확인을 지연하지 말고 즉시 CPR 재개
교육용 시뮬레이터: 실제 장비 조작 교육을 대체하지 않습니다. 에너지는 장비별 제조사 권장값과 기관 프로토콜을 우선합니다.
